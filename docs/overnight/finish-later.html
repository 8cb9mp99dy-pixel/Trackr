1 Let GitHub accept the push Must

Why: the update includes automatic test runs for GitHub (files in .github/workflows/). GitHub only accepts those from a login that has the workflow permission, and the one saved on your Mac doesn't. So GitHub refused the whole push.

Pick one of these three:

OptionHow
A. Install GitHub's tool (recommended)In Terminal, one line at a time: brew install ghgh auth logingh auth setup-git Choose GitHub.com, HTTPS, and "Login with a web browser". This login includes the workflow permission, and it lets Claude open pull requests for you next time.
B. Edit your tokenOn github.com: your photo → Settings → Developer settings → Personal access tokens. Open the token this Mac uses and tick workflow (for a fine-grained token: Repository permissions → Workflows: Read and write). Save.
C. Push without the test runsTell Claude "push without CI" and approve when Claude Code asks to rewrite the unpushed commits. Everything goes live except the automatic test runs, which wait switched off in docs/integrations/github-workflows/.

  Then tell Claude: "push".

2 Check the live app after the push Must

  1.   Wait about 2 minutes, then open the app on your phone.
  2.   Close it and open it again (the app updates itself on the second start).
  3.   Check that your numbers look the same as before, and that the loan is still not in your net worth.
  4.   Open Budget: there is now a Forecast tab. If you see it, the update worked.

If something looks wrong, tell Claude what you see. The previous version is one command away.

3 Replace your Twelve Data key Must

Why: your key for live stock prices is written in the public code (app.js), so anyone could use it up. It was already there before the overnight run.

  1.   Tell Claude: "remove the Twelve Data key from the code". The app will then read the key from Settings only.
  2.   Sign in on twelvedata.com and create a new key. Then delete (revoke) the old one.
  3.   Paste the new key yourself in the app: Settings → Display → Twelve Data API key. Never paste it into the chat.
